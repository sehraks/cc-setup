## Features

| Area | What you get |
| --- | --- |
| **Moderation** | Member moderation, timeouts, warnings, offense history, and message cleanup for authorized staff. |
| **Server management** | Server and member info, role selection, staff-role tools, channel controls, and temporary voice/text room workflows where configured. |
| **Community** | Reminders, anonymous confessions, fun/social commands, and personal role menus. |
| **AI Agent & CC AI Companion** | Conversational help in supported channels, including AI-backed replies and supported actions. |
| **Music & media** | Supported music search/download and social-media workflows. Availability may depend on the server's channels, Booster status, and service health. |
| **Guild Panel** | A web interface for supported server settings and bot status, with Discord sign-in for eligible server members. |
| **Connected services** | Optional AI, weather, and other integrations, depending on service availability and configuration. |

Features and command permissions may change as CC develops. The [command guide](commands.md) is a practical overview, not a guarantee that every command is enabled in every server.

## Getting started

1. Open the [CC home page](https://cc-discord.onrender.com).
2. Follow the Discord invite or setup instructions there.
3. Add CC to a server only if you have permission to manage that server.
4. Review the [command guide](commands.md), and use Discord's slash-command suggestions to see the commands available to you.
5. Grant only the Discord permissions CC needs for the features you plan to use.

### A feature isn't working?

Check these first:

- **Permissions:** does the command require staff or specific Discord permissions?
- **Channel or Booster restrictions:** some features are limited to certain channels or Boosters.
- **Service status:** the supporting service (AI, music, weather, etc.) may be offline.

Still stuck? Ask in the [Discord server](https://discord.gg/RXqeCuKPFt).
